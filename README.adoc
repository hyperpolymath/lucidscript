= LucidScript
:toc: preamble
:icons: font

PureScript / Haskell-syntax AffineScript. Write code that looks like PureScript, get affine resource guarantees and typed-wasm output — running in any browser, Node, Deno, or WASI runtime.

== What it is

LucidScript is link:https://github.com/hyperpolymath/affinescript[AffineScript] with its `lucid` face pre-selected. PureScript and Haskell developers will recognise: `module Foo where`, `data Maybe a = Just a | Nothing`, `case e of`, `\x -> body`, `if then else`, `let in`, `--` comments, and equation-style function definitions.

The semantic core is already aligned with PureScript — row polymorphism, ADTs, effects, and type classes are native to AffineScript. LucidScript is largely an aesthetic translation layer plus indentation-to-brace lowering.

This repo is a **brand surface only**. The compiler lives in link:https://github.com/hyperpolymath/affinescript[affinescript]. This repo carries:

* Examples idiomatic to PureScript / Haskell developers
* Documentation aimed at the typed-FP community
* A `lucid` shim CLI that aliases `affinescript --face lucid`
* Migration notes for the parts of PureScript that map cleanly versus the parts that need re-thinking

== Hello

`examples/hello.affine`:

[source,affine]
----
-- face: lucidscript

module Hello where

effect IO {
  fn println(s: String) -> ();
}

main :: -{IO}-> ()
main () = println("Hello, LucidScript!")
----

== Install

[source,bash]
----
opam install affinescript
git clone https://github.com/hyperpolymath/lucidscript
cd lucidscript
----

== Use

[source,bash]
----
# Direct, via affinescript:
affinescript eval --face lucid examples/hello.affine
affinescript compile --face lucid examples/hello.affine -o hello.wasm

# Or via the lucid shim:
./bin/lucid eval examples/hello.affine

# Or via the justfile:
just run examples/hello.affine
just preview examples/hello.affine    # show the canonical lowering
----

Source files use the canonical `.affine` extension. The face is selected by the `-- face: lucidscript` pragma on the first comment line, or by the `--face lucid` flag.

== Different faces, same cube

LucidScript is one of six established faces over the AffineScript core:

* AffineScript — the canonical face
* link:https://github.com/hyperpolymath/rattlescript[RattleScript] — Python-style
* link:https://github.com/hyperpolymath/jaffascript[JaffaScript] — JavaScript / TypeScript-style
* **LucidScript** — PureScript / Haskell-style (this repo)
* link:https://github.com/hyperpolymath/cafescripto[CafeScripto] — CoffeeScript-style
* link:https://github.com/hyperpolymath/pseudoscript[PseudoScript] — pseudocode-style

== Why LucidScript

PureScript is small but its community is highly aligned with what AffineScript already does. Row polymorphism, effects, ADTs, type classes — these are native to AffineScript's core, not bolted on. LucidScript gives PureScript developers a runtime story (typed-wasm to browsers / Node / native) without abandoning the language they like, and adds affine-typed resource guarantees on top.

== Limitations (deferred)

Some PureScript surface features need AST-level rewrites that the text-to-text face transformer doesn't yet handle:

* Multi-clause function definitions (`fact 0 = 1; fact n = n * fact (n-1)`)
* `do`-notation desugaring beyond the trivial form
* `where`-block hoisting

These are tracked in link:https://github.com/hyperpolymath/affinescript/blob/main/examples/faces/README.adoc[the affinescript faces README]. Until they land, write the explicit forms (`case ... of`, `let ... in ...` instead of `where`).

Function application uses canonical paren syntax `f(x)` rather than Haskell currying `f x`. This is a deliberate constraint to keep the lowering text-based.
